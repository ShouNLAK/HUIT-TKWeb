## 🎯 Nội dung Chi tiết

### 📌 Tuần 1 & 2 - HTML Nền tảng
**Các chủ đề:**
- Cấu trúc tài liệu HTML và các thẻ văn bản cơ bản
- Các cấp heading, danh sách, định dạng nội dung
- Thiết kế bảng dữ liệu với `table`, `thead`, `tbody`, `caption`

**Bài tập mẫu:**
- Tạo trang HTML giới thiệu
- Dựng bảng danh sách thông tin cá nhân
- Trình bày bảng có cấu trúc rõ ràng và dễ đọc

---

### 📌 Tuần 3 - HTML Nâng cao
**Các chủ đề:**
- Nhúng media với `audio`, `video`, `img`
- Xây dựng biểu mẫu với `form`, `input`, `select`, `textarea`
- Tổ chức cấu trúc semantic (`section`, `header`, `footer`)

**Bài tập mẫu:**
- Trang phát audio/video
- Form nhập liệu người dùng
- Trang nội dung dùng semantic tag

---

### 📌 Tuần 4 & 5 - CSS Cơ bản và Box Model
**Các chủ đề:**
- Cú pháp CSS, selector, cách liên kết stylesheet
- Định dạng màu, nền, font, khoảng cách
- Box model: `margin`, `border`, `padding`

**Bài tập mẫu:**
- Trang nội dung có nền ảnh và nền màu
- Bố cục khối tin tức bằng CSS
- Định dạng typography theo yêu cầu giao diện

---

### 📌 Tuần 6 & 7 - CSS Nâng cao
**Các chủ đề:**
- Hiệu ứng hình ảnh với `filter`
- Thuộc tính `display`, `position`
- Trạng thái liên kết (`:link`, `:visited`, `:hover`, `:active`)
- Bố cục nâng cao với `z-index`, `grid`

**Bài tập mẫu:**
- Gallery hiệu ứng filter
- Demo style cho hyperlink
- Dàn trang khối nội dung theo lưới

---

### 📌 Tuần Ôn Tập - Tích hợp giao diện hoàn chỉnh
**Các chủ đề:**
- Ghép toàn bộ kiến thức đã học vào một trang web hoàn chỉnh
- Tổ chức layout gồm header, menu, sidebar, product grid, footer

**Bài tập mẫu:**
- Xây dựng trang mẫu `FlowerShop` với HTML + External CSS

### ⚙️ Yêu cầu Hệ thống
- Trình duyệt hiện đại: Chrome, Edge, Firefox
- Trình soạn thảo: VS Code hoặc bất kỳ IDE hỗ trợ HTML/CSS

